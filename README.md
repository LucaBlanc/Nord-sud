# Nord ou Sud ?

Application de vote : une ville apparaît sur la carte de France et chacun vote, une seule fois par ville, si elle est au nord ou au sud. Les résultats sont visibles par ville, sur une carte et dans un classement.

## Maquette

`maquette/index.html` : maquette des 5 écrans mobiles (Voter, Résultat, Carte, Classement, Fiche ville). Ouvrir le fichier dans un navigateur. Les chiffres sont des exemples.
